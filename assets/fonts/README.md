# Fonts

`GoogleSans-500-subset.woff2` and `GoogleSans-700-subset.woff2` are static instances of
[Google Sans](https://fonts.google.com/specimen/Google+Sans) (wght 500 / 700), subset to
Basic Latin plus `· ★ … — – ‘ ’ “ ”`. They are embedded as data URIs in the rendered SVG so the
scene keeps its typography inside GitHub's Camo image proxy, which blocks external font requests.

Google Sans is distributed by Google Fonts under the SIL Open Font License 1.1.
